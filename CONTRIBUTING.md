# Contributing

## Local setup

Use Node.js 20 or newer, then run `npm ci` and `npm run dev`.

## Before opening a pull request

- Keep the CSV import format backward compatible.
- Run `npm run check`.
- Do not add user sales data or API keys to the repository.
- Add or update a test when changing forecasting or data-quality logic.

## Product principles

BazarSight is decision-support software. Present forecasts as planning estimates, not guaranteed business outcomes.
